# 统计口径与栏目逻辑（权威）

> 代码位置：工作区 `工地台账/看板.html`。本文件描述的公式与线上看板**逐行对应**，改动任一栏目后必须按 §7 恒等式复验。

## 1. 计价模型（所有栏目的公共底座）

### 1.1 定价来源 `vehiclePricing()`
遍历「类型=设备 且 分类=台班单价」的记录，按设备聚合：
- 单位含「小时」→ 记入 `hrRates[项目或地点]`（按小时单价，元/小时）。
- 单位「元/天」（或未标）且带「项目」→ 记入 `proj[项目]`（**项目专属单价**，不污染设备基础价）。
- 不带「项目」→ 作为设备基础价 `fee`（元/天），并记 `loc`。

再遍历「类型=开销 且 分类=人工工资」且带「设备」的记录 → 取 `wage` = 该设备**司机日工资**。

### 1.2 取价函数
```js
rateOf(p, proj)      // 按天单价：优先项目专属 proj[proj]，否则基础价 p.fee
hourlyRateOf(p,loc,proj)  // 按小时单价：优先 proj[proj] → loc[loc] → __base__
```

### 1.3 计价开关
```js
isUnpriced(r)   // 备注+工作内容 命中 /单价未确定|暂不计价|待定价|未定价/
isHour(r)       // 单位 === "小时"
locUnpricedMap(price)  // 仅当期年份：把含未定价记录的 (设备,地点) 打标
isCounted(d,loc,umap)  // = !umap[d+"\0"+(loc||"")]  → 该组是否计价
```
**要点**：`isCounted` 按 **(设备,地点)** 判定；**自有车不再排除**。未定价组只计天数不计金额。

### 1.4 年份与周期
```js
curYear()   // 运行当年
recYear(r)  // 记录年份 = (日期||录入时间)[0:4]
CYCLE_DEVICES = ["小松360"]   // 仅它走「每月8号→次月7号」
periodOf(dev, date)  // 小松360→cycleOf()；其余→自然月
```
台班类统计**默认仅当期年份**（`recYear(r)===curYear()`）。2025 焦作高速 500.8h 不计入当下。

## 2. 分组键

- 车辆利润 / 设备汇总 / 收入对账：按 **(设备 + 地点)**，地点取记录「地点」字段，缺则用定价地点兜底。
- 经营台账：按 **(设备 + 项目)**。实测车辆记录中「地点≈项目」，故两者口径等价。
- 分组分隔符 `SEP = "\u0000"`（避免与字段值冲突）。

## 3. 各栏目公式

### 3.1 车辆利润 `renderVeh()`（列「车辆利润」）
- **编辑表单**：按 (设备,地点) 分行，单价输入框 `data-feerec` 精确对应该地点的「台班单价」记录；工资输入框仅首行 `data-wagerec`。保存处理器按记录 ID 更新。
- **KPI**（当期年）：
  - 台班费收入(理论) `ti = Σ 台班天数 × 该地点单价`（**按天**）
  - 司机工资 `tc = Σ 台班天数 × 日工资`
  - 净利润 `tn = ti − tc`
  - 平均日净利 `tn / 台班天数`；副标签注明「另按小时计 ¥x（工资待核）」。
- **两图**：各车净利润对比（`inc−wc`，按 设备·地点）、日净利对比（`该地单价 − 日工资`）。
- **利润明细**：按 (设备,地点) 行；小时组显示「待确认(按小时计/工时工资待核)」；未定价组显示「待定价」。
- 末行调用 `renderVehBiz(price, umap)`。

### 3.2 经营台账 `renderVehBiz(price, umap)`（列「经营台账 · 台班→收入→利润（按项目）」）
链式：`台班 × 单价 = 应得台班费；− 工资成本 = 利润`。
列：设备｜项目｜台班/小时｜单价｜应得台班费｜已记收入｜应收未结｜工资成本｜利润。
- 台班组：`counted` 时 `fee=tb×rate`、`wc=tb×wage`、`pro=fee−wc`；否则「待定价」。
- 小时组：有小时单价则 `fee=hr×hrRate`（如王村铺 37×250=9250），利润「待确认(工时工资待核)」。
- 已记收入 / 应收未结：按 (设备,项目) 归集。
- **合计**：应得台班费 = **按天部分**（88090），小时部分以「＋按小时另计 ¥9,250」单列**不并入**；工资 = 按天部分；利润 = 按天部分。→ 与 §7 恒等式一致。
- 无台班但有收支的设备（小松500）也建行归集。

### 3.3 设备汇总 `renderEqViz()`（列「设备汇总」）
- 台班/工时/收入/应收/应付均按 **(设备,地点)** 分组；当期年。
- KPI：在账设备数、总台班天数、总工时、**已计价理论利润** `tn=Σ(dy×rate−dy×wage)`、设备相关收入/应收/应付。
- 表行：台班天数｜工时｜已记收入｜应收未结｜应付未结｜理论利润｜状态（已计价/待定价/按小时/纯收支）。

### 3.4 收入 & 收入对账 `renderInc()`
- 收入 KPI：总收入、本月收入、待回款(应收)、涉及项目。
- 走势/分类/项目：`bars`。
- **对账表**（当期年，按天）：`theoFee = Σ 台班天数 × 该地点单价`（`isCounted` 过滤）；台班天数合计；实际已入账；差额 = 理论 − 实际。

### 3.5 勾稽校验 `renderRecon()`（收支总览内）
- ① 理论台班费（台班类设备 × 单价，含项目专属价）= 88090
- ② 台班类设备已记收入；③ 台班类设备应收未结；已确认回款 = ②+③；回款率 = 已确认÷①
- 差额（待回款/在途）= ① − 已确认回款（正=在途，负=需核查）
- ④ 全部已记收入｜⑤ 应收未结(全部)｜⑥ 应付未结(全部)｜净敞口 = ⑤−⑥
- 非台班设备（小松500等）单列，不污染恒等式。

### 3.6 台班周期统计 `renderTb()`（列「台班周期统计」）
- 设备下拉：`#tbDev`（全部设备/各设备）。
- 台班 = 「类型=设备 且 分类=台班 且 非小时」求和；工时 = 「单位=小时」求和。
- KPI：累计台班、累计工时、本周期/本月台班、本周期/本月工时；**每个数值下方按「地点」拆分呈现**（`locBreakdown` + `kpiLocSub`）。
- 表：逐日明细（台班/工时/地点/备注）、周期汇总（台班/工时/出勤天数/日均台班）。
- 相关账目：自动匹配该设备的非台班记录（收入/欠款/开销/出勤）。

### 3.7 欠款台账 `renderDebt()`（列「欠款台账」）
- 应收未结 / 应付未结 / 净敞口(应收−应付) / 欠款笔数。
- 按对方聚合柱图；账龄（30天内/31-90天/90天以上，按当前日期−记录日期）。
- `isOpen(r) = r["欠款状态"] !== "已结清"`；操作按钮切换结清状态。

### 3.8 收支总览 `renderKpis()` / `renderFlow()` / `renderExpViz()`
- 收入合计、支出合计、净结余、应收未结、应付未结、净敞口、总工时、每工时成本、设备工时、台班油耗(L/h)。
- 流水明细：按类型计数与金额、收支趋势（日/周/月粒度）。

## 4. 按小时计的处理

- 单位=小时 → `isHour`。**不折台班、不进按天合计**，单独成行。
- 有元/小时单价（王村铺 210 250元/小时）→ 应得台班费 = 小时 × 单价；**工时工资未知则净利润标「待确认(工时工资待核)」**。
- 无元/小时单价（焦作高速 500.8h）→ 「待确认(按小时计)」，不计金额。

## 5. 未定价的处理

- 未定价组：只计台班天数、不计金额；利润显示「待定价」。
- 按 (设备,地点) 判定，不连坐整台车。

## 7. 一致性恒等式（改动后必验）

```
理论台班费(按天)  ==  车辆利润KPI 台班费收入
                  ==  经营台账 合计 应得台班费
                  ==  设备汇总 已计价理论利润+工资
                  ==  收入对账 理论台班费
                  ==  勾稽校验 ① 理论台班费

净利润            ==  车辆利润KPI == 经营台账合计 == 设备汇总已计价理论利润

恒等式            ==  理论台班费 = 司机工资 + 净利润
```

| 经营台账 合计 | ¥90,123（＋小时另计 9,250） | ¥35,460 | ¥54,663 |
| 设备汇总 | ¥90,123 | ¥35,460 | ¥54,663 |
| 收入对账 | ¥90,123 | — | — |

## 8. 已知边界情况

- **2025 焦作高速**：小松360 500.8h，待定价，`recYear≠当期` → 车辆利润/设备汇总/收入对账/勾稽 **均不计入**；经营台账因不按年份过滤会显示该行（不计金额，不影响合计）。
- **利润明细 KPI 与 明细行**：KPI 台班费为按天合计（88090），明细里王村铺行显示 9250——已在 KPI 副标签注明「另按小时计」。
- **台班天数 111.2 天**含自有车（铲车50 40 + 小松360 32 天等）；**设备汇总/收入对账的台班天数**同样是 111.2（全部台班设备），二者一致。
