## 2. ledger.py（流水表 CLI 封装）

**运行环境**：必须用 managed venv 的 python：
```
~/.workbuddy/binaries/python/envs/default/Scripts/python.exe（把 ~ 换成你的用户目录，例如 C:/Users/你的用户名/.workbuddy/...）
```
（系统 `python` 是 3.11，脚本内部 `sys.executable` 会复用同一解释器调用 skill 脚本。）

**依赖（`_resolve_skill_dir` 已自动解析，通常无需手改）**：脚本会按以下顺序定位 `library` 技能的 database 子脚本——① 应用内置 `app.asar.unpacked`（F:/ C:/ D:/ 常见盘符）；② 用户插件缓存 `~/.workbuddy/plugins/cache/workbuddy-builtin/<版本>/skills/library`；③ 全盘 glob 兜底；全部找不到才回落到 F: 内置目录。若换环境报找不到脚本，可手动把 `_resolve_skill_dir()` 的返回值指向实际的 library 目录。

**子命令**：

| 命令 | 用法 |
|---|---|
| add | `ledger.py add records.json`，records.json 为**记录数组**（或单对象），中文键，脚本自动包 oneof |
| list | `ledger.py list [--type 开销] [--from 2026-10-01] [--to 2026-10-31]` |
| update | `ledger.py update fix.json`，`[{"record_id":"xxx","备注":"...","工时":10}]` |
| delete | `ledger.py delete del.json`（`["id1","id2"]` 或 `{"record_ids":[...]}`）；**不可逆，先列清单经用户确认** |
| confirm | `ledger.py confirm <record_id> 已确认` 或 `... 有疑问 --doubt "金额看不清"` |
| pending | `ledger.py pending`（列出「待确认」「有疑问」） |
| config | `ledger.py config`（读配置表：开销分类/收入分类/设备/人员/项目） |

**字段包装规则**（脚本自动处理，手写 JSON 时按扁平值写即可）：
- 日期/录入时间 → `{"date": "..."}`
- 金额/工时/数量 → `{"number": ...}`
- 类型/欠款方向/欠款状态/录入来源/确认状态 → `{"select": "..."}`
- 其余 → `{"text": "..."}`
- 原始凭证 → `{"attachment":[{name,url,fileType,fileSize,mediaType}]}`

**坑位**：
- `add` 返回 `{"written":N,"failed":M}`；即使 `failed:0` 也**要回查 `list` 确认**（`success:true` 历史上出现过"假成功"）。
- `list` 已**内置 cursor 翻页**（按 `next_cursor`/`has_more` 自动续拉），流水超过 200 条也不会丢数据；如需强制单页可临时改 `page_size`。
- 云写入在受限沙箱可能被拦截，需要 `dangerouslyDisableSandbox` 重试。

## 3. import_html.py（看板重导云端）

```
~/.workbuddy/plugins/cache/workbuddy-builtin/<版本>/skills/library/page/import_html.py
```
（`<版本>` 形如 `5.8.x-wb.########.g########.########`；若不确定，用 `find ~/.workbuddy -name import_html.py` 定位。注意路径是 `skills/library/page/`，不是旧版的 `skill-library`。）
用法（在工作区 `工地台账/` 目录下）：
```
<python> import_html.py 看板.html --node-block-id <你的看板页ID>
```
成功输出 `KS_IMPORT_OK {...}`。**改完看板必须重导**，否则用户看到的还是旧版。
重导只更新页面，不改数据表。

## 4. 看板（看板.html）实现要点与坑

- 单文件 HTML；`ALL` 由云端 DSDK `loadAll()` 填充（**不是** CLI 取数）。`DATABASE_ID` 在脚本顶部。
- 筛选：`buildFilters()` + `applyFilter()` → 生成 `FILTERED`；`render()` 逐个重绘各栏目。
- 页面环境 `sorts` 参数可能被 reject → 排序改在客户端做。
- `loadAll` 要有 `.catch` 兜底；空数据显示显式提示。
- 主键统一 `ridOf(r)`；日期缺失退回「录入时间」（`dayOf`）。
- 绑定字段的 DOM 需带字面量 `data-sp-database-id="<你的流水表ID>"`；「快速记一笔」表单要配 localStorage 草稿（`DRAFT_KEY`，新增输入框记得加进 `DRAFT_FIELDS`）。
- **网页录入（云端记账，不依赖本地电脑）**：数据表与看板都在云端，用户用手机/浏览器打开空间页 → 点「快速记一笔」→ 表单经云端 DSDK `db.addRecord` 直写，`录入来源=网页录入`、`录入时间=当前`、留空「原始记录」会自动按表单生成摘要。表单字段：日期/类型/分类/金额/人员/工时/设备/数量/单位/地点/工作内容/对方/项目/凭证文件/识别文字/确认状态/备注/原始记录。设备台班记法：类型=设备、填设备+地点+数量(如 1)+单位(台班/小时)、分类留空。欠款：类型=欠款、选方向。此路径与「对话汇报」（agent 口述拆分入账）并存。
- 语法校验：本沙箱 lint 会卡死（124），改用 Node：
  ```
  node -e "const fs=require('fs');const h=fs.readFileSync('看板.html','utf8');const re=/<script[^>]*>([\s\S]*?)<\/script>/g;let m,i=0,b=0;while((m=re.exec(h))){i++;try{new Function(m[1])}catch(e){b++;console.log(i,e.message)}}console.log('scripts',i,'err',b)"
  ```
