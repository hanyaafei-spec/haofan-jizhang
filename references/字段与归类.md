# 字段与归类方法

> 数据表：**工地台账·流水** `databaseId = <你的流水表ID>`
> 配置表（人员/项目/分类/设备枚举）：`<你的配置表ID>`（用 `ledger.py config` 读）

## 1. 字段清单

| 字段 | 说明 |
|---|---|
| 日期 | 事情**实际发生**的日期（与录入时间可不同） |
| 类型 | 出勤 \| 开销 \| 收入 \| 设备 \| 欠款 |
| 人员 | 出勤是谁；或相关人（司机、对方） |
| 分类 | 依类型而定，见下 |
| 金额 | 开销/收入/欠款的金额（元） |
| 工时 | 出勤/设备的工时（小时） |
| 数量 | 台班数、台班单价、小时数、加油升数——**含义由单位决定** |
| 单位 | 天 \| 台班 \| 小时 \| 元/天 \| 元/小时 \| 升 |
| 对方 | 欠款对象（欠谁/谁欠）、收入来源 |
| 项目 | 工程/工地名（延津、洪州、王村铺、南阳、焦作高速…） |
| 地点 | 施工地点；**车辆统计按 (设备,地点) 分组**，多数情况地点=项目 |
| 设备 | 车辆/机械名（铲车50、210、小松360、红360、小松500…） |
| 欠款方向 | 应收（别人欠我） \| 应付（我欠别人） |
| 欠款状态 | 未结清 \| 已结清 |
| 工作内容 | 干了什么活 |
| 备注 | 补充说明；**未定价标记写这里**（见 §4） |
| 原始记录 | **用户原话**（务必保留，可追溯） |
| 录入时间 | 落账时间（ISO，取当前时间） |
| 录入来源 | 对话汇报 \| 网页录入 \| 手动修正 |
| 原始凭证 | 图片/视频附件（attachment，存凭证夹） |
| 凭证说明 | 凭证的文字说明 |
| 图片识别文字 | 图上识别出的文字 |
| 确认状态 | 待确认（默认） \| 已确认 \| 有疑问 |
| 存疑点 | 估算/不确定之处，逐条写明 |

## 2. 类型 × 分类 枚举

| 类型 | 分类（可选值） | 备注 |
|---|---|---|
| 出勤 | 工人出勤 | 数量=1/0.5，单位=天 |
| 开销 | 油料、人工工资、材料费、机械费、伙食费、水电费、维修保养、运费、办公劳保、住宿、其他 | 人工工资若带「设备」字段＝该车司机日工资 |
| 收入 | 工程款、分包结算、其他收入 | — |
| 设备 | 台班、台班单价 | **台班**=干活记录；**台班单价**=定价记录 |
| 欠款 | 应收挂账、应付挂账 | 必填「欠款方向」 |

## 3. 口语 → 字段 归类判定表

| 用户说 | 拆成 | 关键字段 |
|---|---|---|
| "李四王五全天挖基坑" | 出勤 ×2 | 人员=李四/王五，数量=1，单位=天 |
| "张三半天" | 出勤 | 数量=0.5，单位=天 |
| "210 干了 9 小时" 但按天结 | 设备/台班 | 数量=1（按天），单位=台班 |
| "210 王村铺干了 37 小时，按小时算" | 设备/台班 | 数量=37，单位=**小时**，地点=王村铺 |
| "昨天半天+今天全天" | 设备/台班 ×2 或合并 | 0.5 + 1 = 1.5 台班 |
| "白天1个班+晚上1个班" | 设备/台班 | 数量=2 |
| "加了 320 升柴油" | 开销/油料 | 数量=320，单位=升，金额=油费 |
| **自有车加油** | **不记油费**（禁记） | 自己的车自己的油 |
| "收了 8000 工程款" | 收入/工程款 | 金额=8000 |
| "老黄还欠我 18775" | 欠款 | 方向=应收，状态=未结清，对方=老黄 |
| "我欠冯胜伟机械费 400" | 欠款 | 方向=**应付**，状态=未结清，对方=冯胜伟 |
| "延津 210 一天 850" | 设备/台班单价 | 设备=210，项目/地点=延津，数量=850，单位=**元/天** |
| "王村铺 210 按 250 一小时" | 设备/台班单价 | 设备=210，地点/项目=王村铺，数量=250，单位=**元/小时** |
| "司机一天 300" | 开销/人工工资 | 设备=210，金额=300 |

**拆分原则**：一轮汇报里只要出现不同「类型」的信息，就拆成多条；同一类型同一设备同一天的多项可合并。

## 4. 是否计价的判定

- **未定价**：备注或工作内容含「单价未确定 / 暂不计价 / 待定价 / 未定价」→ 该 **(设备,地点)** 组只计台班天数，**不计金额**（不猜价）。
- 判定是**按 (设备,地点) 分组**做的，**不连坐整台车**（例：焦作高速未定价不影响小松360南阳台班）。
- **自有车**（铲车50、小松360）**照常计价计入利润**；「自有」只作展示标签，不再排除。

## 5. 单位口径

| 单位 | 用于 | 数量含义 |
|---|---|---|
| 天 | 出勤 | 1 / 0.5 |
| 台班 | 设备台班 | 台班数（1、0.5、2…） |
| 小时 | 设备按小时计 | 小时数，**不折台班** |
| 元/天 | 台班单价（按天） | 日台班费（用「数量」字段承载） |
| 元/小时 | 台班单价（按小时） | 小时台班费 |
| 升 | 油料 | 加油量 |

时间换算：一天 10 小时；半天 5 小时（仅用于台班折算 0.5）；整日工时按 8 小时（出勤口径）。

## 6. 录入口径（固定）

1. 录入来源 = `对话汇报`；录入时间 = 当前时间。
2. **原始记录 = 用户原话**（一字不改，最重要的可追溯字段）。
3. 确认状态 = `待确认`（默认）。回复时逐条列出请核对；用户确认后才改 `已确认`。
4. 缺项按行业常理估算，并把估算写进「存疑点」，回复中明示。**金额/单价/欠款/工时工资缺则不留空也不瞎填**，标「有疑问」并提问。

## 7. 凭证（图片/视频）

1. 先上传到凭证夹（`<你的凭证夹ID>`），拿到 attachment。
2. 写入「原始凭证」字段。
3. 图上文字写到「图片识别文字」。
4. 看不清/拿不准 → 写「存疑点」+ 确认状态「有疑问」并主动提问。

## 8. 欠款方向判定（最易错，错了要问）

- **应收 = 别人欠我**（我该收钱）。
- **应付 = 我欠别人**（我该付钱）。
- 结清只改「欠款状态」为 `已结清`，**不删记录**；看板自动算 应收未结 / 应付未结 / 净敞口。
- 现金还款未经核实**不擅自冲减**（如郑州老黄余额），标注待核。
